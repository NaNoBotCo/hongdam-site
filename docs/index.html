What we build

Six things most agencies won't attempt

Every service below is drawn from something already running at an address you can open.

ท

Thai-first, bilingual by design

ไทยเป็นหลัก อังกฤษเป็นชั้นแสดงผลจริง

Thai as the canonical language with English as a true display layer — not a bolted-on translation plugin. Built for how Thai readers actually search and scan.

☰

LINE-native apps

แอปในไลน์ ไม่ต้องจำรหัสผ่าน

LIFF + Official Account integration for zero-password sign-in — invoicing, bookings, announcements, all inside the app people already have open.

◐

Offline-first & installable

ไม่มีสัญญาณก็ยังใช้ได้

Progressive web apps that keep working with no signal — real for Thailand's patchier rural connectivity, not a checkbox feature.

✦

Custom generative design

กราฟิกวาดด้วยโค้ด เฉพาะแบรนด์

Procedural, code-drawn visuals built for the brand — the gold vines growing on this very page, the dust signature above, the instruments below. All drawn live, no libraries.

⚏

Data pipelines & crawlers

จากข้อมูลกระจัดกระจาย สู่สารบัญที่ค้นได้

Turning messy, scattered real-world data — listings, archives, directories — into structured, searchable, maintainable catalogs.

◈

Static-first builds

เร็ว โฮสต์ถูก ย้ายง่าย

A page assembled at build time and served as files — cheap to host, quick on a rural connection, and portable to any server you can point a domain at.
