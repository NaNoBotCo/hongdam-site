ภาษา

  • ทะเบียนบ้าน
  • สูติบัตร ทะเบียนสมรส ทะเบียนหย่า

  • หนังสือรับรองและรายการเดินบัญชีธนาคาร
  • สัญญาจ้างและสลิปเงินเดือน
  • เอกสารใบอนุญาตทำงาน
  • ใบแสดงผลการเรียนและวุฒิบัตร
  • ประวัติการรักษาและใบรับรองแพทย์
  • สัญญาเช่า
  • จดหมายจากหน่วยงาน โรงเรียน และโรงพยาบาล

ธุรกิจ

  • เมนู ป้าย และป้ายราคา

  • สัญญาสองภาษาเทียบกันในหน้าเดียว
  • เว็บไซต์และแอป ที่สตูดิโอสร้างหรือแปล
  • โพสต์ LINE, Facebook และ TikTok
